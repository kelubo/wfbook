# 节气谚语

## 什么是二十四节气

二十四节气是中国古代根据太阳位置划分的季节变化规律，是中国传统文化的重要组成部分。

## 春季节气谚语

### 立春（2月4/5日）

立春是二十四节气中的第一个节气，标志着春季的开始。

1. **立春一日，水暖三分。**
   - 说明立春后气温开始回升，水温逐渐变暖。

2. **立春晴，雨水匀。**
   - 如果立春天气晴朗，预示着整个春天雨水均匀。

3. **立春不晴，还要冷一月零。**
   - 如果立春天气不好，寒冷还会持续一个多月。

4. **立春打雷，十处猪栏九处空。**
   - 立春打雷，可能会有瘟疫等灾害。

### 雨水（2月19/20日）

雨水节气，降雨开始增多。

1. **雨水有雨，一年多水。**
   - 如果雨水这天降雨，预示全年雨水充足。

2. **雨水无雨，夏至无雨。**
   - 如果雨水这天不下雨，夏至也可能干旱。

3. **雨水惊蛰寒，芒种水淹岸。**
   - 雨水和惊蛰期间寒冷，预示芒种时节可能有大水。

4. **雨水到来地解冻，化一层来耙一层。**
   - 雨水后土地解冻，是春耕的好时机。

### 惊蛰（3月5/6日）

惊蛰时节，春雷惊醒蛰伏的动物。

1. **惊蛰雷鸣，成堆谷米。**
   - 惊蛰打雷，预示丰收。

2. **惊蛰不耙地，好比蒸馍走了气。**
   - 惊蛰后要及时耕地，否则影响收成。

3. **惊蛰刮北风，从头另过冬。**
   - 惊蛰刮北风，天气还会变冷。

4. **惊蛰过，暖和和，蛤蟆老角唱山歌。**
   - 惊蛰后天气变暖，青蛙开始鸣叫。

### 春分（3月20/21日）

春分时节，昼夜平分。

1. **春分有雨到清明，清明下雨无路行。**
   - 春分下雨，清明可能有大雨。

2. **春分无雨到清明。**
   - 春分不下雨，一直到清明都可能干旱。

3. **春分不暖，秋分不凉。**
   - 春分天气不暖和，秋分天气也不会凉爽。

4. **春分前后怕春霜，一见春霜麦苗伤。**
   - 春分前后的春霜会损害麦苗。

### 清明（4月4/5日）

清明时节，天气晴朗，草木茂盛。

1. **清明前后，种瓜点豆。**
   - 清明是播种的最佳时机。

2. **清明雨纷纷，必定是丰年。**
   - 清明下雨，预示丰收。

3. **清明无雨旱黄梅，清明有雨水黄梅。**
   - 清明无雨，黄梅季节可能干旱；清明有雨，黄梅季节雨水充足。

4. **清明刮动土，要刮四十五。**
   - 清明刮风，可能会持续刮很长时间。

### 谷雨（4月20/21日）

谷雨时节，降雨增多，利于谷物生长。

1. **谷雨前后，种瓜点豆。**
   - 谷雨是播种的最后时机。

2. **谷雨有雨兆雨多，谷雨无雨水来迟。**
   - 谷雨下雨，全年雨水充足；谷雨无雨，可能干旱。

3. **谷雨下雨，四十五日无干土。**
   - 谷雨下雨，接下来天气会比较湿润。

4. **谷雨不种花，心头像蟹爬。**
   - 谷雨不种花，心里会很着急。

## 夏季节气谚语

### 立夏（5月5/6日）

立夏标志着夏季的开始。

1. **立夏不下，小满不满，芒种不管。**
   - 立夏不下雨，小满水量不足，芒种也无法耕种。

2. **立夏到，补蛋要趁早。**
   - 立夏有吃鸡蛋的习俗。

3. **立夏刮阵风，小麦一场空。**
   - 立夏刮风，可能影响小麦收成。

4. **立夏前后，种瓜点豆。**
   - 立夏前后是播种的好时机。

### 小满（5月20/21日）

小满时节，麦类作物开始饱满。

1. **小满不满，干断田坎。**
   - 小满时节雨水不足，可能导致干旱。

2. **小满不满，芒种不管。**
   - 小满水量不足，芒种无法耕种。

3. **小满大满江河满。**
   - 小满到到大满期间，雨水增多，江河水位上升。

4. **小满前后，种瓜种豆。**
   - 小满前后是播种的好时机。

### 芒种（6月5/6日）

芒种时节，麦类作物成熟收割。

1. **芒种芒种，连收带种。**
   - 芒种既要收割小麦，又要播种秋粮。

2. **芒种火烧天，夏至雨绵绵。**
   - 芒种天气炎热，夏至可能有连阴雨。

3. **芒种不下雨，夏至十八河。**
   - 芒种不下雨，夏至可能有大水。

4. **芒种忙忙种，夏至谷怀胎。**
   - 芒种忙着播种，夏至时谷物开始孕育。

### 夏至（6月21/22日）

夏至是北半球白昼最长的一天。

1. **夏至无雨三伏热。**
   - 夏至不下雨，三伏天会很热。

2. **夏至有雨，仓里有米。**
   - 夏至下雨，预示丰收。

3. **夏至东风摇，麦子水里捞。**
   - 夏至刮东风，可能有大雨，影响小麦收割。

4. **夏至不过不热，冬至不过不寒。**
   - 夏至过后天气才会真正变热。

### 小暑（7月7/8日）

小暑时节，天气开始炎热。

1. **小暑不算热，大暑三伏天。**
   - 小暑还不是最热的时候，大暑才是真正的热天。

2. **小暑过，一日热三分。**
   - 小暑过后，每天都比前一天热。

3. **小暑打雷，大暑破圩。**
   - 小暑打雷，大暑可能有大水冲破圩堤。

4. **小暑南风，大暑旱。**
   - 小暑刮南风，大暑可能干旱。

### 大暑（7月22/23日）

大暑是一年中最热的时期。

1. **大暑热不透，大热在秋后。**
   - 如果大暑不是很热，秋天可能会更热。

2. **大暑不热，五谷不结。**
   - 大暑不热，可能影响谷物成熟。

3. **大暑大雨，百日见霜。**
   - 大暑下大雨，可能一百天后会下霜。

4. **大暑小暑，灌死老鼠。**
   - 大暑小暑期间雨水多，连老鼠都可能被淹死。

## 秋季节气谚语

### 立秋（8月7/8日）

立秋标志着秋季的开始。

1. **立秋之日凉风至。**
   - 立秋后天气开始转凉。

2. **立秋不立秋，六月二十头。**
   - 立秋可能在农历六月二十左右。

3. **立秋有雨样样收，立秋无雨人人忧。**
   - 立秋下雨，五谷丰登；立秋无雨，可能歉收。

4. **立秋处暑有阵头，三秋天气多雨水。**
   - 立秋和处暑期间有阵雨，整个秋天雨水较多。

### 处暑（8月22/23日）

处暑时节，炎热逐渐消退。

1. **处暑不出头，割谷喂老牛。**
   - 处暑时谷物还没抽穗，就只能割来喂牛了。

2. **处暑天还暑，好似秋老虎。**
   - 处暑后天气可能还会炎热，称为"秋老虎"。

3. **处暑有雨十八江，处暑无雨干断江。**
   - 处暑下雨，雨水充足；处暑无雨，可能干旱。

4. **处暑雷声唱，阴雨天气多。**
   - 处暑打雷，阴雨天气较多。

### 白露（9月7/8日）

白露时节，气温下降，露水变白。

1. **白露身不露。**
   - 白露后天气转凉，不宜再赤身露体。

2. **白露秋分夜，一夜凉一夜。**
   - 白露到秋分期间，每天都比前一天凉。

3. **白露早，寒露迟，秋分种麦正当时。**
   - 这是北方种麦的谚语。

4. **白露下雨，路干即雨。**
   - 白露下雨后，路刚干可能又会下雨。

### 秋分（9月23/24日）

秋分时节，昼夜再次平分。

1. **秋分秋分，昼夜平分。**
   - 秋分这天白天和黑夜一样长。

2. **秋分不生田。**
   - 秋分后不宜再耕种。

3. **秋分有雨来年丰。**
   - 秋分下雨，预示来年丰收。

4. **秋分早，霜降迟，寒露种麦正当时。**
   - 这是南方种麦的谚语。

### 寒露（10月8/9日）

寒露时节，天气变凉，露水变寒。

1. **寒露脚不露。**
   - 寒露后天气变冷，要注意脚部保暖。

2. **寒露到霜降，种麦日夜忙。**
   - 寒露到霜降是种麦的繁忙时期。

3. **寒露有雨，以后多雨。**
   - 寒露下雨，预示后期雨水较多。

4. **寒露无雨，百日无霜。**
   - 寒露不下雨，可能一百天内不会下霜。

### 霜降（10月23/24日）

霜降时节，开始降霜。

1. **霜降见霜，谷米满仓。**
   - 霜降降霜，预示丰收。

2. **霜降不割禾，一天少一箩。**
   - 霜降后要及时收割，否则会减产。

3. **霜降无霜，主来岁饥荒。**
   - 霜降不降霜，来年可能歉收。

4. **霜降配羊清明羔，天气暖和有青草。**
   - 霜降时配种的羊，清明时产羔，天气暖和有青草吃。

## 冬季节气谚语

### 立冬（11月7/8日）

立冬标志着冬季的开始。

1. **立冬晴，一冬晴；立冬阴，一冬阴。**
   - 立冬天气晴朗，整个冬天可能都晴朗；立冬阴天，整个冬天可能都阴天。

2. **立冬无雨一冬晴。**
   - 立冬不下雨，整个冬天可能都干旱。

3. **立冬北风冰雪多，立冬南风无雨雪。**
   - 立冬刮北风，冬季可能多冰雪；立冬刮南风，冬季可能少雨雪。

4. **立冬补冬，补嘴空。**
   - 立冬有进补的习俗。

### 小雪（11月22/23日）

小雪时节，开始下雪。

1. **小雪不见雪，来年长工歇。**
   - 小雪不下雪，来年可能歉收，长工没事做。

2. **小雪雪满天，来年必丰年。**
   - 小雪下雪，预示来年丰收。

3. **小雪封地，大雪封河。**
   - 小雪后土地开始冻结，大雪后河流开始结冰。

4. **小雪不耕地，大雪不行船。**
   - 小雪后不宜耕地，大雪后不宜行船。

### 大雪（12月7/8日）

大雪时节，降雪增多。

1. **大雪下雪，来年雨不缺。**
   - 大雪下雪，来年雨水充足。

2. **大雪不冻，惊蛰不开。**
   - 大雪时河水不结冰，惊蛰时可能还不化冻。

3. **大雪封河，小雪封山。**
   - 大雪后河流结冰，小雪后山区积雪。

4. **大雪晴天，立春雪多。**
   - 大雪天气晴朗，立春可能有大雪。

### 冬至（12月21/22日）

冬至是北半球白昼最短的一天。

1. **冬至不过不寒。**
   - 冬至过后天气才会真正变冷。

2. **冬至晴，正月雨；冬至雨，正月晴。**
   - 冬至晴天，正月可能多雨；冬至下雨，正月可能晴朗。

3. **冬至大如年。**
   - 冬至是重要的节日，如同过年。

4. **冬至吃饺子，不冻耳朵。**
   - 冬至有吃饺子的习俗。

### 小寒（1月5/6日）

小寒时节，天气寒冷。

1. **小寒胜大寒，常见不稀罕。**
   - 小寒有时比大寒更寒冷，这种现象并不少见。

2. **三九不封河，来年冰雹多。**
   - 如果三九期间河水没有结冰，预示来年可能会有较多冰雹天气。

3. **小寒暖，立春雪；小寒寒，惊蛰暖。**
   - 小寒温暖的话，立春可能会下雪；小寒寒冷的话，惊蛰时节会比较温暖。

4. **小寒时处二三九，天寒地冻北风吼。**
   - 小寒节气正处于"二九"和"三九"期间，是一年中最寒冷的时期，北风呼啸，天寒地冻。

### 大寒（1月20/21日）

大寒是一年中最冷的时期。

1. **大寒到顶点，日后天渐暖。**
   - 大寒过后，天气逐渐变暖。

2. **大寒不寒，春分不暖。**
   - 大寒不冷，春分可能也不暖和。

3. **大寒见三白，农人衣食足。**
   - 大寒期间下三次雪，预示丰收。

4. **大寒猪屯湿，三月谷芽烂。**
   - 大寒期间猪圈潮湿，三月谷物可能腐烂。

## 节气养生

### 春季养生

- **饮食**：清淡为主，多吃蔬菜
- **运动**：适当锻炼，早睡早起
- **情志**：保持心情舒畅

### 夏季养生

- **饮食**：清热解暑，多吃瓜果
- **运动**：避免高温时段，适量运动
- **情志**：心静自然凉

### 秋季养生

- **饮食**：滋阴润燥，多吃梨、百合
- **运动**：适度锻炼，早睡早起
- **情志**：保持平静

### 冬季养生

- **饮食**：温补为主，多吃羊肉、红枣
- **运动**：室内锻炼，注意保暖
- **情志**：静养
