# 温度

## 什么是温度

温度是物体冷热程度的物理量，是分子平均动能的标志。

## 常见温标

### 摄氏温标（°C）

**发明者**：安德斯·摄尔修斯（Anders Celsius），瑞典天文学家，1742年提出

**定义**：
- 标准大气压下，水的冰点为0°C
- 标准大气压下，水的沸点为100°C

**应用范围**：国际通用，中国大陆、欧洲、亚洲大部分国家使用

### 华氏温标（°F）

**发明者**：丹尼尔·加布里埃尔·华伦海特（Daniel Gabriel Fahrenheit），德国物理学家，1724年提出

**定义**：
- 冰、水和氯化铵混合物的温度为0°F
- 人体温度约为96°F（现代修正为98.6°F）
- 水的沸点为212°F

**应用范围**：美国、巴哈马、伯利兹、开曼群岛等少数国家

### 列氏温标（°Ré）

**发明者**：勒内·列奥米尔（René Antoine Ferchault de Réaumur），法国物理学家，1730年提出

**定义**：
- 水的冰点为0°Ré
- 水的沸点为80°Ré

**应用范围**：曾在欧洲广泛使用，现已基本淘汰，仅在某些领域有历史意义

## 绝对温标

### 开尔文温标（K）

**发明者**：威廉·汤姆森（William Thomson），即开尔文勋爵，1848年提出

**定义**：
- 绝对零度为0 K（约-273.15°C）
- 水的冰点为273.15 K
- 水的沸点为373.15 K

**应用范围**：科学研究、热力学计算

### 兰氏温标（°R）

**发明者**：威廉·约翰·麦夸恩·兰金（William John Macquorn Rankine），英国工程师，1859年提出

**定义**：
- 绝对零度为0°R（约-459.67°F）
- 水的冰点为491.67°R
- 水的沸点为671.67°R

**应用范围**：美国工程领域

## 温标转换公式

### 摄氏 ↔ 华氏

```
°C = (°F - 32) × 5/9
°F = °C × 9/5 + 32
```

### 摄氏 ↔ 列氏

```
°C = °Ré × 100/80 = °Ré × 1.25
°Ré = °C × 80/100 = °C × 0.8
```

### 摄氏 ↔ 开尔文

```
K = °C + 273.15
°C = K - 273.15
```

### 华氏 ↔ 兰氏

```
°R = °F + 459.67
°F = °R - 459.67
```

## 温度单位符号规范

### 正确写法

| 温标 | 符号 | 示例 |
|------|------|------|
| 摄氏 | °C | 25°C |
| 华氏 | °F | 77°F |
| 列氏 | °Ré | 20°Ré |
| 开尔文 | K | 298 K（注意无度符号） |
| 兰氏 | °R | 537°R |

### 常见错误

- ❌ 25 C（缺少度符号）
- ❌ 25° C（度符号和单位之间有空格）
- ❌ 25K（开尔文应保留空格）

## 温度相关概念

### 温差

两个温度之间的差值，单位与温度相同。

### 温度梯度

温度随空间位置的变化率，单位为°C/m或K/m。

### 热平衡

两个物体温度相同，没有热传递发生。

### 热膨胀

物体温度升高时体积增大的现象，与温度变化成正比。

## 实际应用

### 气象

| 天气 | 温度范围 | 说明 |
|------|----------|------|
| 极寒 | < -40°C | 冻伤风险极高 |
| 寒冷 | -40 ~ 0°C | 需要保暖衣物 |
| 凉爽 | 0 ~ 15°C | 舒适温度 |
| 温暖 | 15 ~ 25°C | 最适宜人体 |
| 炎热 | 25 ~ 35°C | 需要防暑 |
| 酷热 | > 35°C | 中暑风险 |

### 烹饪

| 烹饪方式 | 温度范围 | 说明 |
|----------|----------|------|
| 慢炖 | 60 ~ 80°C | 低温慢煮 |
| 焖煮 | 90 ~ 95°C | 保持微沸 |
| 沸腾 | 100°C | 水的沸点 |
| 煎烤 | 150 ~ 250°C | 高温烹调 |

### 工业

| 应用 | 温度范围 | 说明 |
|------|----------|------|
| 冷藏 | 0 ~ 5°C | 食品保鲜 |
| 冷冻 | -18 ~ -20°C | 食品冷冻 |
| 退火 | 500 ~ 700°C | 金属热处理 |
| 熔化 | > 1000°C | 金属冶炼 |
