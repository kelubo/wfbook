# 应急

## 什么是应急

应急是指在突发事件发生时，采取的一系列紧急措施和准备工作。

## 急救知识

### 心肺复苏（CPR）

心肺复苏是在心脏骤停时采取的急救措施，包括胸外按压和人工呼吸。

**操作步骤**：

1. **安全评估**：确保现场安全，避免自身受伤
2. **判断意识**：轻拍患者肩膀，大声呼唤："你还好吗？"
3. **检查呼吸**：观察胸部起伏，检查时间不超过10秒
4. **拨打急救电话**：立即拨打120，告知地点、情况
5. **胸外按压**：
   - 位置：两乳头连线中点（胸骨下半部）
   - 姿势：双手重叠，用掌根按压
   - 深度：5~6厘米（成人）
   - 频率：100~120次/分钟
6. **人工呼吸**：
   - 仰头抬颏法打开气道：一手掌根压住额头，另一手食指中指抬起下巴
   - 捏住鼻子，口对口吹气，每次吹气约1秒，看到胸部起伏
   - 按压与呼吸比例：30:2（30次按压后进行2次人工呼吸）

**注意事项**：
- 按压时手臂伸直，垂直向下用力
- 避免过快或过慢按压
- 单人施救时持续进行，直到专业人员到达

### 海姆立克急救法

用于解除气道异物梗阻（窒息）。

**成人/儿童操作步骤**：

1. **站在患者身后**，双臂环抱患者腰部
2. **握拳**：一手握拳，拇指侧抵住患者腹部（肚脐上方两指处）
3. **另一只手抓住拳头**，快速向上向内冲击腹部
4. **重复**：直到异物排出或患者失去意识

**婴儿操作步骤**：

1. **俯卧姿势**：用前臂支撑婴儿，头部略低
2. **背部拍击**：用手掌根部在婴儿背部两肩胛骨之间拍击5次
3. **翻转婴儿**：转为仰卧姿势
4. **胸部冲击**：用两指在婴儿胸部两乳头连线下方按压5次
5. **重复**：交替进行背部拍击和胸部冲击

### 止血方法

#### 指压止血法

- **适用**：动脉出血（出血速度快、鲜红色）
- **方法**：用手指或手掌按压出血部位近心端的动脉血管
- **常见部位**：
  - 手部：按压手腕内侧动脉
  - 前臂：按压肘部内侧动脉
  - 下肢：按压大腿根部动脉

#### 加压包扎止血法

- **适用**：静脉出血（出血速度较慢、暗红色）
- **方法**：
  1. 用无菌纱布覆盖伤口
  2. 用绷带或布条加压包扎
  3. 包扎时松紧适度，以能止住出血又不影响血液循环为宜

#### 止血带止血法

- **适用**：四肢大出血，其他方法无法止血时
- **方法**：
  1. 在出血部位近心端绑止血带
  2. 止血带与皮肤之间垫纱布或衣物
  3. 记录绑止血带的时间
  4. 每隔40~50分钟放松一次，每次放松1~2分钟

**注意事项**：
- 止血带止血可能导致肢体坏死，需谨慎使用
- 必须记录时间，避免长时间绑扎

### 骨折固定

**操作步骤**：

1. **检查伤情**：确认骨折部位，检查有无伤口、出血
2. **处理伤口**：如有出血，先止血再固定
3. **固定**：
   - 用夹板、木板、树枝等硬物固定
   - 固定范围应包括骨折部位的上下两个关节
   - 夹板与皮肤之间垫柔软物品
4. **包扎**：用绷带或布条固定夹板
5. **冷敷**：骨折部位冷敷，减轻肿胀和疼痛
6. **搬运**：保持骨折部位稳定，避免二次损伤

**常见骨折固定方法**：

| 骨折部位 | 固定方法 |
|----------|----------|
| 前臂骨折 | 用夹板固定前臂，用三角巾悬吊 |
| 上臂骨折 | 用夹板固定上臂，用三角巾悬吊 |
| 小腿骨折 | 用夹板固定小腿，膝部和踝部固定 |
| 大腿骨折 | 用夹板固定大腿，髋部和膝部固定 |
| 颈椎骨折 | 用颈托固定，保持头部稳定 |

### 烧伤处理

**操作步骤**：

1. **冲**：立即用冷水冲洗烧伤部位15~30分钟
2. **脱**：小心脱去烧伤部位的衣物，必要时剪开
3. **盖**：用干净纱布或毛巾覆盖伤口
4. **送**：严重烧伤（面积大、深度深、特殊部位）立即送医院

**烧伤程度分类**：

| 程度 | 表现 | 处理方法 |
|------|------|----------|
| Ⅰ度 | 皮肤发红、轻微肿胀、疼痛 | 冷水冲洗、涂抹烫伤膏 |
| Ⅱ度 | 水泡、皮肤破损、剧烈疼痛 | 冷水冲洗、覆盖纱布、送医 |
| Ⅲ度 | 皮肤发黑、发硬、无痛感 | 立即送医，切勿自行处理 |

### 中暑急救

**中暑类型**：

| 类型 | 表现 | 处理方法 |
|------|------|----------|
| 先兆中暑 | 头晕、乏力、出汗、口渴 | 转移到阴凉处、补充水分 |
| 轻症中暑 | 体温38°C以上、面色潮红、心跳加快 | 冷水擦拭身体、饮用清凉饮料 |
| 重症中暑 | 体温40°C以上、意识模糊、昏迷 | 立即送医、降温处理 |

**急救措施**：

1. **迅速转移**：将患者转移到阴凉通风处
2. **降温处理**：
   - 解开衣物
   - 用冷水喷洒或擦拭身体
   - 用风扇或扇子吹风
3. **补充水分**：
   - 意识清醒者：饮用含盐清凉饮料
   - 意识不清者：不要喂水，立即送医

### 电击急救

**操作步骤**：

1. **切断电源**：立即关闭电源开关或用绝缘物体（如木棍、塑料棒）挑开电线
2. **检查呼吸心跳**：如呼吸心跳停止，立即进行心肺复苏
3. **处理伤口**：如有烧伤，按烧伤处理方法处理
4. **送医**：立即拨打120，送往医院治疗

**注意事项**：
- 切勿直接接触触电者，避免自身触电
- 高压电触电时，需由专业人员处理

### 溺水急救

**操作步骤**：

1. **救上岸**：将溺水者救上岸，注意自身安全
2. **检查意识呼吸**：观察溺水者是否有意识和呼吸
3. **清除异物**：如有呕吐物或异物堵塞气道，立即清除
4. **心肺复苏**：如呼吸心跳停止，立即进行心肺复苏
5. **送医**：立即拨打120，送往医院治疗

**注意事项**：
- 不要进行"控水"操作，以免延误心肺复苏
- 专业人员到达前持续进行急救

## 不同场景应急包

### 家庭应急包

- 基础物资 + 家庭常用药品
- 适合地震、火灾、洪水等

### 户外应急包

- 轻量化物资 + 野外生存工具
- 适合徒步、露营等

### 车载应急包

- 汽车急救工具 + 应急启动电源
- 适合车辆故障、交通事故

## 应急准备建议

### 定期检查

- 每季度检查一次应急包
- 更换过期药品
- 补充消耗物资

### 家庭演练

- 每年进行一次应急演练
- 熟悉逃生路线
- 练习使用灭火器材

### 个人培训

- 参加急救培训
- 学习基本急救技能
- 获取急救证书

## 常见突发事件应对

### 地震

1. **室内**：躲在桌子下、墙角
2. **室外**：远离建筑物、电线杆
3. **逃生**：走楼梯，不要乘电梯

### 火灾

1. **报警**：拨打119
2. **逃生**：低姿势、捂口鼻
3. **灭火**：小火可用灭火器

### 洪水

1. **转移**：向高处转移
2. **切断电源**：关闭总电源
3. **准备**：准备漂浮物

### 台风

1. **加固**：加固门窗
2. **储备**：储备食物和水
3. **撤离**：听从政府撤离通知

### 雷电

1. **室内**：关闭电器、远离窗户
2. **室外**：远离树木、高地
3. **防雷**：使用避雷针
